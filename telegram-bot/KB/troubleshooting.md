# Отстраняване на проблеми

## Проблеми с входа

| Проблем                   | Решение                                                                                                        |
| ------------------------- | -------------------------------------------------------------------------------------------------------------- |
| "Грешен имейл или парола" | Проверете caps lock, опитайте admin@mertm.bg / mertm2024!                                                      |
| Бял екран след логин      | Изчистете кеша (Ctrl+Shift+Del), опитайте инкогнито                                                            |
| Страницата не зарежда     | Проверете локалната мрежа. Ако backend-ът е в рестарт (self-host на Mac Mini M4), изчакайте 30 сек и пробвайте |

## Проблеми с поръчки

| Проблем                   | Решение                                                |
| ------------------------- | ------------------------------------------------------ |
| Не мога да създам поръчка | Проверете дали сте избрали клиент И поне един продукт  |
| Поръчката не се запазва   | Проверете дали всички задължителни полета са попълнени |
| Грешна сума в поръчката   | Проверете цените на продуктите и количествата          |

## Проблеми с фактури

| Проблем                    | Решение                                                    |
| -------------------------- | ---------------------------------------------------------- |
| Фактурата не се генерира   | Поръчката трябва да има поне един продукт и валиден клиент |
| PDF не се изтегля          | Опитайте с друг браузър (Chrome работи най-добре)          |
| Грешни данни във фактурата | Проверете данните на клиента в секция "Партньори"          |

## Проблеми с имейл

| Проблем                      | Решение                                                            |
| ---------------------------- | ------------------------------------------------------------------ |
| Имейлът не се изпраща        | Проверете имейл адреса. SMTP настройките може да изискват внимание |
| Клиентът не получава фактура | Проверете спам папката. Имейлът идва от magicgamermd@gmail.com     |

## Системни проблеми

| Проблем                 | Решение                                                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------------------------------ |
| Backend не отговаря     | Проверете `systemctl status mertm-backend` или `docker ps` на хост машината. GET /health трябва да върне 200 |
| Бавна работа            | Проверете `docker stats` / натоварване на базата. В пиковите часове е нормално                               |
| Данните не се обновяват | Натиснете F5 или бутон "Обнови". Кешът може да показва стари данни                                           |

## Как да докладвам бъг

Изпратете следната информация:

1. Какво правехте (стъпки за възпроизвеждане)
2. Какво очаквахте да се случи
3. Какво се случи реално
4. Скрийншот (ако е възможно)
5. Браузър и устройство
