# Ръководство за администратора

## Вход в системата

1. Отворете https://mert-m-demo.pages.dev
2. Въведете: admin@mertm.bg / mertm2024!
3. Натиснете "Вход"

## Управление на продукти

- **Преглед:** Меню "Продукти" → списък с всички продукти
- **Търсене:** Използвайте полето за търсене по име, SKU или категория
- **Добавяне:** Бутон "Нов продукт" → попълнете формата → "Запази"
- **Редактиране:** Кликнете на продукт → редактирайте полетата → "Запази"
- **Наличности:** Всеки продукт показва текуща наличност. Обновява се автоматично при поръчки

## Управление на поръчки

- **Нова поръчка:** Меню "Поръчки" → "Нова поръчка"
  1. Изберете клиент (или създайте нов)
  2. Добавете продукти от каталога
  3. Задайте количества
  4. Прегледайте обобщението
  5. Натиснете "Създай поръчка"
- **Статуси:** Нова → В обработка → Изпратена → Доставена
- **История:** Всяка поръчка пази пълна история на промените

## Генериране на фактури

1. Отворете поръчка
2. Натиснете "Генерирай фактура"
3. Системата автоматично попълва данните
4. Прегледайте и натиснете "Създай"
5. Фактурата се генерира като PDF — можете да я изтеглите или изпратите по имейл

## Управление на клиенти

- **Списък:** Меню "Партньори" → всички регистрирани клиенти
- **Нов клиент:** "Добави партньор" → попълнете ЕИК, име, адрес, контакт
- **Търсене по ЕИК:** Системата може автоматично да попълни данни от CompanyBook

## Аналитика и справки

- **Табло:** Начален екран с ключови показатели
- **Продажби:** Графики по период, продукт, клиент
- **Наличности:** Продукти с ниска наличност, предупреждения
